# Сверка реализации с ТЗ «Описание бота АМА РС»

Исходная версия для сверки — `047a39b`. Таблица сопоставляет разделы ТЗ
с кодом и локальными проверками. «Есть» означает, что описанная часть
реализована. Полнота раздела оценивается по графе «Осталось».

| Раздел ТЗ | Есть в коде | Осталось |
| --- | --- | --- |
| 1, 9, 12. Смена предприятия и касса | Два чек-листа, ночной график, обязательные фото, временные исключения, отдельная кассовая карточка, расхождения, приёмка после iiko, кассовые сроки, проверка срока приёмки кассы и его календаря при активации. Проверки `shifts`, `scheduler`, `cash_operations_sla`. | Полные формы каждого пункта, проверка всех профильных маршрутов и восстановление удалённых тем. |

Срок ответа начинается после доставки. Сводки учитывают причины и неразобранные операции.
